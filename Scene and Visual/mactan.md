# BAYANI: ECHOES OF MACTAN

## COMPLETE SCENE-BY-SCENE VISUAL GAME WORLD PROMPT

Design the complete visual world, environments, characters, gameplay spaces, cinematics, props, lighting, atmosphere, UI transitions and visual storytelling for a third-person action-adventure RPG called:

# BAYANI: ECHOES OF MACTAN

**Genre:** Third-Person Action-Adventure RPG / Historical Fantasy / Time Travel / Exploration / Real-Time Combat

**Setting:** Futuristic Philippines, 2187 + Philippine historical setting around 1521 + Filipino folklore-inspired supernatural world.

**Core fantasy:**

A Filipino teenager from the year 2187 enters a reconstructed memory of the Philippines in 1521 through a futuristic machine called BALIKAN. He explores Limasawa, Cebu and Mactan, discovers archaeological and cultural artifacts, encounters folklore-inspired supernatural beings, fights creatures created from forgotten memories, and eventually witnesses the events surrounding the Battle of Mactan.

The game must feel like a premium cinematic adventure game while remaining distinctly Filipino.

---

# GLOBAL VISUAL STYLE

Use:

**Cinematic stylized realism, high-quality 3D game concept art, realistic tropical environments, believable Filipino characters, detailed materials, cinematic lighting, expressive faces, physically believable clothing, atmospheric environmental storytelling, premium AAA-style adventure presentation.**

Do not copy any existing game's characters, environments, logos or assets.

Do not make the game look like generic medieval European fantasy.

Do not use European castles, knight armor, Viking designs, generic fantasy villages or generic Asian fantasy architecture.

The game must visually communicate:

**Philippines + history + adventure + mythology + mystery + time travel.**

* facial identity

* architecture
